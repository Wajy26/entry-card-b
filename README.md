STARFORGE PACT — a sci-fi deck duel you play offline in a desktop browser. You are the Captain: summon units from four original factions (VOID ◆, SOLAR ▲, FROST ●, TERRA ■), spend growing energy, break the RIVAL's SHIELD guards, and reduce its 30 hull to zero before it does the same to you. Keyboard and mouse, title screen, live duel table, win and loss screens.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network.
